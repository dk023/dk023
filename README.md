## 🚀 Showcase Projects

### 🌾 **Offline Smart Farming System** ⭐ [TOP PROJECT]

**The Challenge:** Rural farmers have zero internet connectivity. They need real-time environmental data.

**My Solution:** IoT system that works completely OFFLINE.

**Tech Stack:** ESP32 | DHT11 | MQ135 | OLED Display | Bluetooth

**What It Does:**
- ✅ Monitors temperature, humidity, air quality, soil moisture in real-time
- ✅ Works with ZERO internet connection
- ✅ Displays alerts on OLED screen + sends Bluetooth notifications
- ✅ 92% sensor accuracy
- ✅ Deployable in any rural location

**Recognition:** 🏆 **National Hackathon Finalist** (Shakti Hackathon 1.0 - Top 20% among 200+ teams)

**Impact:** Empowering 70% of farmers to make data-driven decisions
